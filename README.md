# 🌹 New Collection — Banco de Conteúdo + 10 Carrosséis Virais

**Estratégia completa de conteúdo para @newcollectionoficial** — Perfumaria com 60+ ideias prontas para reels, stories e carrosséis.

## 📱 O que tem dentro

- **Banco de Conteúdo**: 60+ ideias de reels organizados por situação, persona, humor, educativo e atacado
- **4 Semanas de Calendário**: Sequência estratégica de posts pra não cansar a audiência
- **Copys Prontas**: Legendas 100% prontas — só adaptam o nome do produto
- **10 Carrosséis Virais**: Roteiros completos com dicas de design pro Canva
- **100% Mobile First**: Funciona perfeitamente em celular, tablet e desktop
- **Zero Dependências**: HTML puro com SVG inline, sem JavaScript pesado, sem bibliotecas

## 🚀 Deploy Live

## 🏗️ Como Funciona

1. **HTML Puro**: Não precisa de build, não precisa de node_modules
2. **Navegação por Abas**: Clique na aba e veja o conteúdo mudar
3. **Responsive Design**: Redimensione o navegador — tudo se adapta
4. **Deploy Automático**: Todo push no GitHub = atualização automática no Netlify

## 💡 Como Usar

### Editando Localmente

```bash
# Clone o repositório
git clone https://github.com/Cjota221/newcollecrion.git

# Abra o index.html no navegador
# (Ou use um servidor local como Live Server do VS Code)
```

### Fazendo Alterações

```bash
# 1. Edite o index.html no seu editor
# 2. Faça commit
git add .
git commit -m "Sua mensagem aqui"

# 3. Faça push — o Netlify atualiza automaticamente
git push origin main
```
